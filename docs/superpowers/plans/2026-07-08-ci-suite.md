# Full GitHub CI Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the minimal GitHub Actions CI into a full suite: hardened test matrix, separate lint job, bundler-audit security job, Dependabot, and a SimpleCov coverage gate.

**Architecture:** One workflow file (`ci.yml`) with three jobs (test matrix, lint, audit), one Dependabot config, and a coverage gate that lives inside the existing rspec run via SimpleCov started at the top of `spec_helper.rb`. No release workflow (out of scope per spec).

**Tech Stack:** GitHub Actions, `ruby/setup-ruby@v1`, SimpleCov ~> 0.22, bundler-audit ~> 0.9, Dependabot v2 config.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-08-ci-suite-design.md`
- Branch: all commits go on `ci/full-suite`.
- RuboCop enforces double-quoted strings, LF line endings, max line 120; `bundle exec rake` (rspec + rubocop) must stay green after every task.
- Coverage baseline measured 2026-07-08: line 99.77%, branch 87.34%. Gate: `line: 99, branch: 85`.
- Gemfile dev/test group is alphabetically ordered (Bundler/OrderedGems cop).
- Workflow YAML cannot be unit-tested; each task verifies with `bundle exec rake` and `actionlint` (skip actionlint if the binary is absent — note that in the commit run, don't install it).

### Task 2: CI workflow rewrite + Dependabot

**Files:**
- Modify: `.github/workflows/ci.yml` (full rewrite)
- Create: `.github/dependabot.yml`

**Interfaces:**
- Consumes: `bundle exec rspec` (gated, Task 1), `bundle exec rubocop`, `bundle exec bundler-audit check --update` (Task 1).
- Produces: CI jobs `test`, `lint`, `audit` that later docs (Task 3) describe.

- [ ] **Step 1: Replace `.github/workflows/ci.yml` with exactly:**

```yaml
name: CI

on:
  push:
    branches: [master, main]
  pull_request:

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read

jobs:
  test:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    strategy:
      fail-fast: false
      matrix:
        ruby: ["3.2", "3.3", "3.4"]
        experimental: [false]
        include:
          - ruby: "head"
            experimental: true
    continue-on-error: ${{ matrix.experimental }}
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: ${{ matrix.ruby }}
          bundler-cache: true
      - run: bundle exec rspec

  lint:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: "3.4"
          bundler-cache: true
      - run: bundle exec rubocop

  audit:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with:
          ruby-version: "3.4"
          bundler-cache: true
      - run: bundle exec bundler-audit check --update
```

- [ ] **Step 2: Create `.github/dependabot.yml` with exactly:**

```yaml
version: 2
updates:
  - package-ecosystem: bundler
    directory: "/"
    schedule:
      interval: weekly
  - package-ecosystem: github-actions
    directory: "/"
    schedule:
      interval: weekly
```

- [ ] **Step 3: Lint the workflow**

Run: `actionlint` (repo root). Expected: no output, exit 0. If `actionlint` is not installed, run `ruby -ryaml -e 'YAML.load_file(".github/workflows/ci.yml"); YAML.load_file(".github/dependabot.yml"); puts "yaml ok"'` instead — expected: `yaml ok`.

- [ ] **Step 4: Commit**

```bash
git add .github/workflows/ci.yml .github/dependabot.yml
git commit -m "ci: full suite - test matrix 3.2-3.4+head, lint, audit, dependabot"
```
